Case briefing

What you need to know

Simultaneous equations are two equations that are both true at the same time. The solution is the pair of values, x and y, that fits both. On a graph, it's where the two lines (or the line and the curve) cross.

Elimination works for two linear equations. Substitution works when one equation already says y = …, and always when one equation is a quadratic.

  1. Make the coefficients of one letter the same size. Multiply every term, including the right-hand side.
  2. Same signs, subtract. Different signs, add. One letter disappears.
  3. Solve for the letter that's left, then substitute back to find the other.
  4. Check both values in the equation you didn't use. If it works, the case is closed.

WORKED EXAMPLEA forensic unit orders kit. 3 cameras and 2 lamps cost £430. 1 camera and 2 lamps cost £210. Find the price of a camera and of a lamp.

Solution

1Let c = price of a camera, l = price of a lamp: 3c + 2l = 430 and c + 2l = 210
2The l terms match (2l) with the same signs, so subtract: 2c = 220, so c = 110.
3Substitute into the second equation: 110 + 2l = 210, so 2l = 100 and l = 50.
4Check in the first: 3(110) + 2(50) = 330 + 100 = 430 ✓
✓ A camera costs £110 and a lamp costs £50.

  • Turn a word problem into two equations with letters you define.

  • Use the discriminant to decide when a line only touches a curve.
