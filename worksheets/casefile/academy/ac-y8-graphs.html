What to listen for

Ask: across first, then up or down? Coordinates are always (x, y). For y = mx + c, ask which number tells you how steep the line is (m, the gradient) and where it crosses the y-axis (c).

Learn it

What you need to know

Coordinates (x, y): go across to x first, then up or down to y.

To draw a line from its equation, make a table of values: choose some x values, work out each y, plot the points and join them with a ruler.

Every straight line can be written y = mx + c. m is the gradient (how far up for each 1 across; negative means it slopes down). c is the y-intercept (where it crosses the y-axis).

Lines with the same gradient are parallel. x = 3 is a vertical line; y = 3 is a horizontal line.

WORKED EXAMPLEDraw the graph of y = 2x + 1 for x from −1 to 3.

Solution

1Table of values: x = −1, 0, 1, 2, 3 gives y = −1, 1, 3, 5, 7.
2Plot (−1, −1), (0, 1), (1, 3), (2, 5), (3, 7).
3Join them with a ruler: it's a straight line.
✓ The line shown, crossing the y-axis at 1

WORKED EXAMPLEFind the gradient and y-intercept of y = 3x − 2.

Solution

1Compare with y = mx + c.
2m = 3, so it goes up 3 for every 1 across.
3c = −2, so it crosses the y-axis at (0, −2).
✓ Gradient 3, y-intercept −2

WORKED EXAMPLEFind the gradient of the line through (1, 3) and (3, 11).

Solution

1Change in y: 11 − 3 = 8. Change in x: 3 − 1 = 2.
2Gradient = change in y ÷ change in x = 8 ÷ 2.
✓ 4

Mistakes to look out for

  • Coordinates the wrong way round: (2, 3) is 2 across and 3 up, not 3 across.
  • Reading the gradient as the first number: in y = 7 − 3x, the gradient is −3.
  • Mixing up x = 5 (vertical) and y = 5 (horizontal).
  • Plotting points correctly but joining them freehand instead of with a ruler.
