What to listen for

Ask: what does it go up by each time, and how does that help with the nth term? The difference becomes the number in front of n. Then check the rule by putting n = 1 in: it should give the first term.

Learn it

What you need to know

A term-to-term rule says how to get from one term to the next: add 4, multiply by 3.

The nth term (position-to-term rule) gives any term from its position. For a sequence that goes up by the same amount each time, the nth term is difference × n + something.

A function machine turns an input into an output. To go backwards, do the inverse operations in reverse order.

  1. Find the difference between terms: that's the number in front of n.
  2. Write the times table of that number under the sequence.
  3. Work out what to add or subtract to get from the times table to the sequence.
  4. Check with n = 1 and n = 2.

WORKED EXAMPLEFind the next two terms of 7, 11, 15, 19, …

Solution

1The terms go up by 4 each time.
219 + 4 = 23 and 23 + 4 = 27.
✓ 23, 27

WORKED EXAMPLEFind the nth term of 5, 8, 11, 14, …

Solution

1The difference is 3, so start with 3n.
23n gives 3, 6, 9, 12. The sequence is 2 more each time.
3So the nth term is 3n + 2. Check: n = 1 gives 5 ✓
✓ 3n + 2

WORKED EXAMPLEA function machine multiplies by 3, then subtracts 4. The output is 23. What was the input?

Solution

1Go backwards with the inverse operations: add 4, then divide by 3.
223 + 4 = 27, then 27 ÷ 3 = 9.
3Check forwards: 9 × 3 − 4 = 23 ✓
✓ 9

Mistakes to look out for

  • Using the first term instead of the difference: 4, 9, 14, … is 5n − 1, not n + 4 or n + 5.
  • Going backwards through a function machine without reversing the order of the steps.
  • Forgetting the sign: a decreasing sequence has a negative number in front of n.
  • Not checking the nth term against the first two terms.
